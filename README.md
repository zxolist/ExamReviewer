# 📚 BizExam Reviewer - การประกอบธุรกิจ ม.5
> เว็บแอปพลิเคชันสำหรับติวและทบทวนข้อสอบวิชาการประกอบธุรกิจ ม.5 แบบทดสอบ 50 ข้อ พร้อมเฉลยละเอียด แฟลชการ์ด และระบบทำซ้ำเฉพาะข้อที่ผิด

---

## 🚀 ฟีเจอร์หลัก (Features)

1. **โหมดการทำข้อสอบ (Dual Quiz Modes):**
   - **โหมดฝึกทบทวน (Practice Mode):** ตรวจคำตอบทันที แสดงคำอธิบายละเอียด มีระบบตัดช้อยส์ 50:50 ระบบอ่านโจทย์ออกเสียง และระบบ Combo Streak
   - **โหมดจำลองสอบจริง (Exam Mode):** จับเวลาเสมือนห้องสอบจริง ไม่สปอยล์เฉลยระหว่างทำ แล้วประเมินผลพร้อมกันตอนส่ง

2. **ระบบนับสถิติสดด้านบน (Upper Live Counter):**
   - นับข้อที่ตอบถูก (✓) ตอบผิด (✗) หรือจำนวนข้อที่ตอบแล้ว/คงเหลือ แบบเรียลไทม์
   - Progress Bar ความคืบหน้า และนาฬิกาจับเวลา ⏱️

3. **🔁 ระบบทำซ้ำเฉพาะข้อที่ผิด (Smart Retry):**
   - เมื่อทำแบบทดสอบเสร็จ สามารถกดปุ่ม **"ทำซ้ำเฉพาะข้อที่ผิด"** เพื่อดึงเฉพาะข้อที่ตอบพลาดมาฝึกทำใหม่จนกว่าจะได้ 100% เต็ม

4. **🗂️ แฟลชการ์ดช่วยจำ (3D Flashcards):**
   - การ์ดพลิก 3 มิติ เพื่อฝึกจำคำตอบและสาระสำคัญก่อนเข้าห้องสอบ

5. **📑 สรุปหัวใจสำคัญ (Cheat Sheet):**
   - รวมสรุป 5 โมดูลสำคัญของวิชาการประกอบธุรกิจ ม.5 (ประเภทธุรกิจ, รูปแบบองค์กร, รัฐวิสาหกิจ, สภาพแวดล้อมธุรกิจ 8M/PEST/FTA, วงจรชีวิต 4 ระยะ)

6. **🔍 คลังค้นหาข้อสอบ (Search Bank):**
   - ค้นหาข้อสอบและเฉลยจากคีย์เวิร์ดได้อย่างรวดเร็ว

7. **🎉 เอฟเฟกต์พลุ Confetti & เสียงดนตรีไพเราะ:**
   - ระบบเสียง Web Audio API ในตัว (ไม่ต้องโหลดไฟล์เสียงเพิ่ม) และพลุฉลองเมื่อทำคะแนนได้ดี

## 🌐 วิธีนำขึ้น Netlify สำหรับให้เพื่อนหรือนักเรียนใช้งานจริง (Deployment Guide)

### วิธีที่ 1: อัปโหลดแบบลากวาง (Drag & Drop) - เร็วที่สุด (1 นาที)
1. เข้าไปที่ [Netlify Drop](https://app.netlify.com/drop)
2. ลากโฟลเดอร์นี้ (`test website 23-11-69`) ไปวางในหน้าเว็บ Netlify
3. Netlify จะสร้าง URL ลิงก์เว็บไซต์ให้ทันที สามารถส่งลิงก์ให้นักเรียนหรือผู้ใช้งานทำข้อสอบได้เลย!

### วิธีที่ 2: Deploy ผ่าน GitHub
1. อัปโหลดไฟล์ทั้งหมดขึ้น GitHub Repository
2. ใน Netlify กด **"Add new site"** -> **"Import an existing project"**
3. เลือก Repository แล้วกด **"Deploy site"** (ระบบมีไฟล์ `netlify.toml` และ `_redirects` รองรับไว้ให้เรียบร้อยแล้ว)
